Frontend Utilities

Tools

一些纯前端的实用/有趣小工具集合。

LLM Frontier Lab

把个人论文语料库里的 2953 篇 LLM 论文按语义聚成 40 个簇后的全景面板：簇散点图、方法族趋势、主题时间演化、簇间桥接、作者合作网络、影响力枢纽与前沿必读。纯前端渲染，数据随语料库同步更新。

LLM Architecture Lab

一个偏研究笔记风格的模型结构浏览器：先看架构，再看参数摘要和静态统计。首版数据包含公开资料整理的合理占位值，后续可用本地脚本替换为实测结果。

KFC Quiz generator

Keyspace Filtering Challenge Quiz generator。一个纯前端的小型谜题生成器：给定唯一答案和线索数量，自动搜索线索组合，保证在 A-Z0-9 无重复字符空间里只有一个解。

JSON Formatter

粘贴一段 JSON，直接在浏览器里完成格式化、压缩、错误定位和复制。

Gradient Lab

一个偏视觉向的小实验，适合快速试出页面背景、按钮或卡片的渐变方案。

Base64 Playground

一个简单直接的 Base64 编解码工具，适合处理中文、日志片段和临时 payload。
